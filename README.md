#  Flutter State Management using Provider

This project explores **state management** in Flutter using the **Provider** package — one of the most widely recommended solutions by the Flutter team. It serves as a beginner-friendly demonstration of managing app state efficiently, with real-time UI updates and a clean architecture.

---

##  What is State Management?

State management is the technique of handling and updating the data (or "state") of an application and reflecting those changes in the UI. In Flutter, it plays a crucial role in building responsive and scalable applications.

---

## Objectives

- Understand the core concept of Provider.
- Learn how to manage application state using ChangeNotifier.
- Implement separation of concerns via model-view architecture.
- Demonstrate clean and maintainable Flutter code using Provider.

---

- **Flutter**
